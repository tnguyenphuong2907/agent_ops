# Nhật ký quyết định của Product Owner

> Chỉ thêm, không sửa dòng cũ. Quyết định bị thay đổi → thêm dòng mới ghi "thay thế D-xxx".
> **Ngoại lệ duy nhất:** cột **Áp dụng cho** được PM *bổ sung thêm* ID (không xoá) khi tạo task mới thuộc epic/ADR đã liệt kê, hoặc khi phát hiện task khác chịu ảnh hưởng.
>
> Cột **Áp dụng cho** ghi các task (`E<nn>-T<nn>`), epic (`E<nn>`: mọi task trong epic) và ADR chịu ảnh hưởng. Ngược lại, mỗi file task cũng liệt kê các D-xxx liên quan trong `links` ở frontmatter.
